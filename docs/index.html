cislunar

A Python toolkit for orbits in Earth-Moon space, built on the circular restricted three-body problem: halo orbits, NRHOs and DROs; transfers and rendezvous; transient orbits; Delta-v budgets; and orbit determination from sparse observations.

User manual A guided tour for readers who know orbits from Kerbal Space Program, with interactive simulations. The page is about 12 MB, so it takes a moment to load. Case study: base stations for satellite servicing Where should a servicing station live? Station Delta-v, the route matrix, and 10 / 100 / 1,000-mission campaigns compared with direct launches.
